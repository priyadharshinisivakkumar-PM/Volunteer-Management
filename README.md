# Volunteer Management System

## Overview

Volunteer Management System is a web-based application designed to manage temple volunteers and visitor passes during special events, full moon, new moon, and regular days.

This system allows public users to register and allows admin to manage registrations, set volunteer limits, and print ID cards.

## Features

* Volunteer registration
* Visitor pass generation
* Admin login
* Admin dashboard
* Limit setting for events
* ID card printing

* Frontend: React + Vite
* Backend: Node.js + Express + PostgreSQL + Supabase Storage
